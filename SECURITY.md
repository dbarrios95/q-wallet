# Política de seguridad

- Reportar vulnerabilidades al equipo por canal privado; nunca mediante issues públicos.
- Prohibido subir secretos al repositorio. gitleaks bloquea el pipeline si detecta alguno.
- Las pruebas ofensivas se ejecutan solo contra la infraestructura propia del proyecto.
- Toda dependencia nueva debe pasar SCA sin hallazgos High/Critical.
